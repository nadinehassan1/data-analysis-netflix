# Netflix Advanced Data Analysis Project

An advanced data analysis and machine learning project focused on exploring Netflix titles data to uncover trends, patterns, and predictive insights.

This project includes extensive Exploratory Data Analysis (EDA), feature engineering, data cleaning, visualization, and machine learning model training using Python.

## Project Objectives
- Analyze Netflix content trends
- Explore relationships between genres, ratings, and release years
- Improve data quality through preprocessing and cleaning
- Perform feature engineering for machine learning
- Compare multiple machine learning models

## Technologies Used
- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data Cleaning & Quality Assessment
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Data Visualization
5. Machine Learning Model Training
6. Model Evaluation & Comparison

## Visualizations
The project contains 10+ visualizations including:
- Content distribution analysis
- Release year trends
- Genre analysis
- Ratings distribution
- Correlation heatmaps
- Comparative charts

## Machine Learning Models
The following ML models were trained and evaluated:
- Logistic Regression
- Random Forest
- Decision Tree
- Support Vector Machine (SVM)

## Key Features
- Advanced EDA techniques
- Feature engineering pipeline
- Data preprocessing and handling missing values
- Multiple ML model comparison
- Insight-driven visual analytics

## Dataset
Netflix titles dataset containing information about movies and TV shows available on Netflix.
